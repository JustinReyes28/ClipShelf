SourceSpool v0.2.1 is now available on npm: download and organize online media references directly from your Windows terminal.

For video editors, motion designers, creators, and researchers, reference clips downloaded from the web often end up scattered across Downloads folders with cryptic filenames and lost source links.

SourceSpool provides a streamlined, keyboard-driven workflow:
1. Paste a public media link from YouTube, Instagram, Facebook, Vimeo, TikTok, or other supported sites.
2. Choose your format (high-resolution video or audio-only) with automatic stream merging via yt-dlp and FFmpeg.
3. Add tags, personal notes, and organize into collections with predictable naming templates.
4. Search and browse your entire library completely offline by title, source URL, tag, or note content.
5. Prevent duplicates with URL and SHA-256 hash checks, and export portable catalogue metadata in clean JSON.

Try it instantly without installation:
npx sourcespool@latest

Or install globally:
npm install -g sourcespool

Requires Windows 11 x64, local NTFS storage, and Node 22 or newer (Node 24 LTS recommended). Built-in guided setup installs verified yt-dlp/FFmpeg on first run.

The app is open-source (MIT licensed) and inspired by Yoinks. Designed for single public media references (no login/cookie walls).
